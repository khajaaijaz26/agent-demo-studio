# Production plan

## Audience and goal

Teachers and school leaders should understand that EdulabsAI connects lesson planning, classroom resources, student work, evidence, reteaching, and family communication. The advertisement should create trust and interest without feeling busy.

## Sequence

| Scene | Message | Visual proof |
|---|---|---|
| One clear idea | Teaching works as a connected loop | Original illustrated learning loop |
| Classroom context | Generation starts from teacher choices | Completed lesson brief still |
| Four resources | One brief creates a coherent package | Lesson overview plus four resource cards |
| Teach and practice | Resources move into live learning | Teaching slide plus student dashboard |
| Evidence to reteach | Reviewed evidence informs the next lesson | Snap & Mark plus Learning Insights |
| Teacher-approved connection | Progress can be shared clearly | Family Digest still and approval illustration |
| Start free | One loop, one next step | Branded finale and beta CTA |

## Release gates

- Manifest stability audit passes.
- All sampled frames are visually inspected at full resolution.
- No black frames or unexpected silence are detected.
- Integrated loudness and true peak are within the master target.
- Output is exactly 1920×1080 at 30 fps.
- Deliverable checksum and release manifest are generated.
