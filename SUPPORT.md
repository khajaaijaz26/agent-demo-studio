# Support

Agent Demo Studio is a community-maintained open-source project.

## Before opening an issue

1. Update to the latest release and run `agent-demo doctor`.
2. Reproduce the problem with the smallest public or generated fixture possible.
3. Run `npm run check`; for media failures also run the relevant `npm run test:creator` or `npm run test:smoke` command from a source checkout.
4. Search existing GitHub issues.

Use the bug template and include the Agent Demo Studio version, Node.js version, operating system, FFmpeg version, exact command or MCP tool, expected result, actual result, and redacted diagnostic output.

Never attach production recordings, cookies, access tokens, passwords, private URLs, customer data, or a creator package containing confidential media. Use GitHub private vulnerability reporting for security issues.

Platform publishing errors often depend on the app's approval status, access-token scopes, account type, privacy options, or current creator limits. Verify the platform response against its official developer documentation before sharing a redacted error.
